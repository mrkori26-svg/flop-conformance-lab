# External Evidence Reuse

The Lab measures external traction as a conversion ladder rather than treating every mention as adoption.

1. REPRODUCTION — an external project acknowledges or uses a reproduction.
2. EVIDENCE_REUSE — it reuses a fixture, result, or evidence artifact.
3. TOOL_REUSE — it runs a Lab verifier or CLI.
4. DEPENDENCY — it pins Lab tooling in a persistent workflow.
5. DURABLE_DEPENDENCY — the dependency remains after relevant upstream change.

Stages are evidence-backed and never inferred from outreach, an open PR, a fork, or our own execution of external code.
